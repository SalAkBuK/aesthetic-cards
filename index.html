01 // DETERMINISTIC GEOMETRY ENGINE
CORE PRIMITIVE

Standard CSS border-radius creates anti-aliased organic curves that degrade at non-standard pixel ratios. Kinetic UI relies exclusively on closed linear mathematical polygons using 8-point chamfer cutoffs:

// 8-Point Chamfer Cutoff Token
--c: 13px;
clip-path: polygon(var(--c) 0, calc(100% - var(--c)) 0, 100% var(--c), 100% calc(100% - var(--c)), calc(100% - var(--c)) 100%, var(--c) 100%, 0 calc(100% - var(--c)), 0 var(--c));
